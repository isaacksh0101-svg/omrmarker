# ScoreLab 사용설명서

> 대상 버전: ScoreLab 2.0.1  
> 대상 사용자: ScoreLab을 설치·운영하는 교사  
> 제품 문의: isaacksh0101@sen.go.kr

## 1. 시작하기

ScoreLab은 교사 PC에 시험과 학생 데이터를 저장하고, 학생이 같은 네트워크에서 브라우저로 접속하는 수업·평가 지원 도구입니다.

1. ScoreLab을 실행합니다.
2. 처음 실행할 때 시험지와 학생 데이터를 저장할 폴더를 선택합니다.
3. 교사용 비밀번호를 설정합니다.
4. 왼쪽 메뉴의 `학생 관리`에서 학생 명단을 준비합니다.
5. `시험지 만들기`에서 시험을 만들고 문항과 정답을 확인합니다.
6. 환경설정에서 학교 내부 네트워크를 선택한 뒤 `시험 감독`의 QR 또는 링크와 시험별 6자리 입장 코드를 학생에게 제공합니다.

학생 데이터는 교사 PC에 저장됩니다. Windows 공용(Public) 네트워크는 학생 접속이 차단됩니다.

## 2. 학생 명단 준비

`학생 관리`에서 번호와 선택사항인 이름을 등록합니다.

- 직접 추가: 번호와 이름을 입력해 한 명씩 추가합니다.
- Excel 가져오기: 양식을 내려받아 명단을 작성한 뒤 가져옵니다.
- 이름 수정: 명단에서 이름을 수정합니다.
- 명단 삭제: 명단 행만 삭제하며 기존 학습 데이터는 별도로 남을 수 있습니다.
- 선택한 학습 데이터 삭제: 체크박스로 전체 또는 원하는 학생을 선택해 응시 기록, 답안, 점수, 문항별 시간, 필기와 화면 이탈 기록을 완전 삭제합니다. 명단은 유지됩니다.

가능하면 학생 이름을 입력하지 않고 번호만 사용하는 것을 권장합니다.

## 3. 시험지 만들기

`시험지 만들기`에서 교과, 학년군, 시험 제목, 제한시간과 시험 방식을 선택합니다.

### 온라인 응시

학생 화면에 문제와 보기를 표시하고 학생이 브라우저에서 답을 입력합니다.

### 종이 시험지 + 마킹

학생은 종이 시험지를 보고 브라우저에서는 답만 마킹합니다.

시험 생성 후 문항, 보기, 배점, 정답과 성취기준을 확인합니다. 모든 문항에 정답이 설정되어야 시험지를 확정할 수 있습니다.

## 4. AI로 시험지 불러오기

AI 기능을 사용하려면 `환경설정 > AI 설정`에서 교사 또는 학교가 발급받은 Gemini API 키를 등록합니다.

- 시험지 사진 또는 PDF로 문항과 보기를 추출할 수 있습니다.
- 정답지에서 정답을 채울 수 있습니다.
- 성취기준 후보를 제안받을 수 있습니다.
- AI 결과는 반드시 교사가 원본과 비교해 수정한 뒤 사용합니다.

학생 이름, 작성 답안, 점수 또는 상담자료가 들어 있는 문서는 업로드하지 마세요. 개인정보가 없는 빈 시험지와 정답지만 사용해야 합니다.

## 5. 학생 접속과 시험 준비

1. 교사 PC와 학생 기기를 같은 학교 내부 네트워크에 연결합니다.
2. `시험 감독`에서 QR 또는 접속 링크를 확인하고 감독할 시험을 추가합니다.
3. 학생은 QR을 스캔하거나 링크를 열어 자신의 번호와 시험 카드의 6자리 입장 코드를 입력합니다.
4. 코드가 확인되면 해당 시험의 대기 화면으로 이동합니다. 연속 시험은 첫 시험 완료 후 자동으로 연결됩니다.
5. 교사는 `접속 학생 확인 후 시작`에서 번호와 인원을 확인한 뒤 시험을 시작합니다.
6. 시험 시작 후에도 올바른 코드를 입력한 학생은 들어올 수 있으며 즉시 시험이 시작됩니다. `시험 종료`를 누르면 신규 입장과 진행 중 응시가 모두 종료됩니다.

학생이 접속하지 못하면 환경설정에서 학교 내부망 어댑터가 선택됐는지 확인하세요. 그래도 안 되면 학교 AP의 기기간 통신 차단 또는 Windows 방화벽에서 포트 4000이 차단됐는지 확인합니다.

## 6. 시험 감독

`시험 감독`에서 시험을 선택하면 학생별 진행 상태를 확인할 수 있습니다.

- 시험 시작: 대기 중인 학생의 시험을 시작합니다.
- 추가시간: 학생별로 1분·5분·10분을 추가할 수 있습니다.
- 강제 제출: 해당 학생의 시험을 즉시 종료합니다.
- 되살리기: 강제 종료되거나 제출된 학생을 다시 응시 상태로 전환합니다.
- 시험 전체 종료: 대기·응시 중인 학생을 제출 처리하고 새 참여를 막습니다.
- 시험 다시 열기: 종료한 시험에 다시 참여할 수 있게 합니다.

학생이 다른 탭이나 창으로 이동하거나 화면을 최소화하면 화면 이탈로 기록되고 시험이 강제로 제출될 수 있습니다. 오탐이나 기기 문제는 교사가 확인한 뒤 재참여 여부를 판단하세요.

## 7. 결과와 리포트

`시험지 관리`에서 시험별 결과를 열 수 있습니다.

- 제출 인원과 점수
- 문항별 정답률과 평균 소요시간
- 주목할 문항
- 성취기준별 정답률
- 학생별 응답 상세와 필기
- Excel 결과 내보내기

`학생별 리포트`에서는 한 학생이 응시한 시험과 문항별 결과를 모아 볼 수 있습니다. 자동 채점과 분석 결과는 교사가 확인한 후 수업·평가·학생 지도에 활용하세요.

## 8. 데이터 저장 위치 변경

설치형 앱에서는 `환경설정 > 데이터 저장 위치`에서 현재 경로를 확인하고 바꿀 수 있습니다.

1. `저장 위치 변경`을 누릅니다.
2. 새 상위 폴더를 선택합니다.
3. 현재 데이터를 새 위치의 `ScoreLab` 폴더로 복사합니다.
4. 앱이 다시 시작되면 시험지·학생 명단·설정을 확인합니다.
5. 새 위치에서 정상 동작하는 것을 확인한 뒤 이전 폴더를 직접 삭제합니다.

데이터 손실을 막기 위해 이전 폴더는 자동으로 삭제하지 않습니다. 삭제 또는 안전한 보관 여부를 확인할 때까지 교사 화면에 경고가 표시됩니다. 이미 파일이 들어 있는 `ScoreLab` 폴더에는 덮어쓰지 않습니다.

## 9. 백업과 복원

`환경설정 > 데이터 백업`에서 범위를 선택합니다.

- 전체: 시험지, 학생 명단과 응시 기록 전체
- 시험지: 문항과 보기만 추가 방식으로 가져오기
- 학생 명단: 현재 명단을 백업 파일의 명단으로 교체
- 성적: 응시·답안·경고 기록을 교체

전체 복원 전에는 기존 DB의 `.bak-시각` 사본이 만들어질 수 있습니다. 백업과 복원 사본에는 학생 정보가 포함될 수 있으므로 학교가 허용한 저장장치에서 직접 보관·삭제하세요.

## 10. 학기 말 데이터 정리

1. 필요한 결과를 학교가 허용한 위치에 내보냅니다.
2. `학생 관리`에서 전체 또는 원하는 학생을 체크해 `선택한 학습 데이터 삭제`를 실행하거나, `환경설정 > 학년도별 성적 데이터 관리`에서 학년도 단위로 일괄 삭제합니다.
3. 더 이상 필요 없는 학생 명단과 시험을 삭제합니다.
4. 환경설정에 표시된 데이터 폴더의 로그·이미지·`.bak` 사본을 점검합니다.
5. 별도로 내려받은 백업과 결과 파일을 점검·삭제합니다.
6. 공용 학생 기기에서는 브라우저 사이트 데이터를 삭제합니다.

## 11. 문제 해결

### 학생이 접속하지 못함

- 교사 PC와 학생 기기가 같은 내부 네트워크인지 확인합니다.
- 환경설정에서 다른 LAN 주소를 선택합니다.
- Windows 방화벽과 학교 AP의 기기간 통신 정책을 확인합니다.
- 공개·게스트 Wi-Fi에서는 사용하지 않습니다.

### 서버 오류로 앱이 열리지 않음

- 이미 실행 중인 ScoreLab 창이 있는지 확인합니다.
- 포트 4000을 사용하는 다른 프로그램을 종료합니다.
- ScoreLab을 종료하고 다시 실행합니다.
- 계속되면 데이터 폴더의 `logs/server.log`와 함께 제품지원 이메일로 문의합니다.

### Gemini 기능이 작동하지 않음

- API 키가 정확한지 확인합니다.
- 현재 모델 목록을 새로고침합니다.
- Google AI Studio의 결제·사용량 한도를 확인합니다.
- 기본 시험 기능은 Gemini 없이도 사용할 수 있습니다.

### 저장 위치 변경 후 데이터가 보이지 않음

- 환경설정에 표시된 현재 저장 경로를 확인합니다.
- 변경 전 폴더는 삭제하지 말고 보관합니다.
- 앱을 완전히 종료한 뒤 다시 실행합니다.

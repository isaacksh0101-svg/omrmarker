## 4. 확정된 운영 원칙

- ScoreLab은 학교 또는 교사가 수업·평가·학습 피드백을 위해 사용하는 로컬 설치형 도구임
- 학생 데이터는 교사 PC에 저장되고 개발자 서버로 전송되지 않음
- 학교가 개인정보처리자이고 개발자는 제품 제공·기술지원자임
- 학교 개인정보 보호책임자는 학교장, 실무 담당부서는 과학정보부임
- 학생·보호자의 권리행사 1차 창구는 ScoreLab을 사용한 담당 교사임
- 학생 학습 데이터 보유기간은 해당 학기 말까지임
- 전체 또는 원하는 학생의 학습 데이터 선택 삭제기능으로 응시·답안·점수·시간·필기·화면 이탈 기록을 삭제함
- 학생 시험 시작 전에 데이터 처리와 화면 이탈 규칙을 안내함
- 교사 로그인과 관리기능은 교사 PC localhost에서만 허용함
- 학생 이름은 선택항목이고 번호만 사용할 수 있음
- Gemini에는 정상 사용 시 개인정보가 없는 빈 시험지·정답지만 전송함
- 학생 데이터에 관한 제품 개발자의 처리위탁 관계는 현재 확인되지 않음
- 결과는 교사가 확인한 후 학교 기준에 따라 성적 처리·학생 지도·학교생활기록 작성 등의 참고자료로 활용할 수 있음

## 5. 코드에서 확인한 데이터 흐름

### 로컬 저장

- `server/src/db/schema.sql`
  - 학생 명단, 시험 세션, 답안·점수·시간·필기, 화면 이탈 기록, 시험·문항·성취기준
- `server/src/services/appSettings.js`
  - 교사 비밀번호 해시, 세션 비밀값, 암호화된 Gemini API 키와 모델 설정
- `electron/main.js`, `electron/preload.js`, `server/src/config.js`
  - 첫 실행에서 선택한 폴더에 DB·uploads·settings·로그 저장
  - 환경설정에서 저장 위치 확인·변경과 기존 데이터 복사 지원
- 학생 브라우저 localStorage
  - 번호, 무작위 시험 접근 토큰과 필기 모드

### 외부 전송

- `server/src/services/aiExtraction.js`
  - 교사가 실행할 때 빈 시험지·정답지, 분석 지시문, 교과·학년군·성취기준을 Gemini로 HTTPS 전송
  - 학생 답안·성적·필기·화면 이탈 기록을 보내는 코드는 없음
- `server/src/services/geminiModels.js`
  - 이용 가능한 모델 목록 확인을 위해 API 키를 Google Gemini Models API로 전송
- 분석·광고·외부 클라우드 DB SDK는 확인되지 않음

### 접근통제

- `server/src/middleware/auth.js`, `server/src/routes/auth.js`, `server/src/index.js`
  - 교사 로그인·관리 API와 교사 화면을 localhost로 제한
  - LAN의 다른 기기에서는 403 응답
- 학생 세션은 무작위 접근 토큰으로 식별

### 삭제

- `server/src/routes/roster.js`, `server/src/db/repo.js`
  - 학생 명단을 유지하면서 해당 학생의 모든 시험 세션과 종속 답안·경고를 삭제
- 시험 영구 삭제
  - 관련 세션·답안·경고를 연쇄 삭제
- 남은 한계
  - 일부 이미지, 로그, `.bak` 사본과 사용자가 내보낸 백업은 별도 점검 필요

## 6. 아직 남은 기술 보완사항

1. 교사 비밀번호를 8자 이상으로 강화하고 반복 실패 제한 적용
2. `xlsx` high 취약점 제거 또는 안전한 대체 라이브러리 적용
3. Gemini 업로드 화면에 개인정보 포함 문서 금지 경고 추가
4. 로그 순환과 보유기간 적용
5. 시험 영구 삭제 시 관련 이미지 정리
6. 백업 파일 보호와 파기 안내 강화
7. 학교 환경별 호환성·동시접속·접근성 시험

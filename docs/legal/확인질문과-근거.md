# ScoreLab 소프트웨어 이용조건·데이터 처리 안내서 확인 질문과 근거

> 이 문서는 교사용 소프트웨어 이용조건과 데이터 처리 안내서 초안을 최종화하기 위해 확인할 질문과 코드상 근거를 정리한 내부 검토 문서입니다. 게시용 문서가 아닙니다.

## A. 반드시 확인할 질문

1. **개인정보처리자는 누구인가요?**
   - 개인 교사, 학교, 교육청 또는 별도 사업자 중 누구 명의로 운영·배포하나요?
   - 확인된 내용: 개인정보 보호 및 권리행사 실무 담당부서는 학교 과학정보부로 정합니다.
   - 운영자/기관명, 개인정보 보호책임자 성명, 소속·직위, 공식 연락처, 이메일을 알려주세요.

2. **ScoreLab은 어디까지 사용하나요? — 확인됨**
   - 확인된 내용: 학교 또는 교사가 사용하는 수업·형성평가·학습 피드백 지원 도구입니다.
   - 결과는 학교 기준과 관련 법령에 따라 교사가 검토한 뒤 성적 처리, 학생 지도 또는 학교생활기록 작성의 참고자료로 활용할 수 있습니다. 공식 행정시스템과 직접 연계되거나 자동 반영되지는 않습니다.
   - 한 학교 내부만 배포하나요, 다른 학교 교사에게도 공개 배포하나요?

3. **학생 개인정보 처리의 법적 근거와 안내 방식은 무엇인가요? — 운영 원칙 확인됨**
   - 확인된 내용: 출석번호·답안·채점·학습분석뿐 아니라 필기 획·문항별 소요시간·화면 이탈·강제 제출 기록도 수업·평가 및 온라인 시험 운영에 필요한 기본 처리로 봅니다. 학생 첫 접속 시 처리 내용과 시험 규칙을 안내하며, 안내 확인을 모든 처리에 대한 포괄적 동의로 간주하지 않습니다.
   - 확인된 내용: 동의를 법적 근거로 하는 선택적·추가 처리에 한해서 학생 또는 법정대리인에게 필요한 사항을 알리고 별도 동의를 받습니다.
   - 남은 확인: 학교 또는 교육기관이 기본 처리에 적용할 구체적인 법령상 근거와 내부 소프트웨어 승인 절차는 무엇인가요?
   - 만 14세 미만 학생에 대해 실제로 동의가 필요한 선택 기능을 운영한다면 법정대리인 확인과 동의 기록 보관 방법을 어떻게 정할까요?

4. **실제 보유기간을 어떻게 정할까요?**
   - 학년도 종료, 성적 확정 후 일정 기간, 학생 전학·졸업 시점 등 구체적인 기준이 필요합니다.
   - 서버 로그, `.bak` DB, 문항 이미지, 백업 파일에도 각각 보유기간을 정할까요?
   - 현재 자동 파기 기능이 없으므로 정한 정책에 맞게 기능을 추가할까요?

5. **Gemini는 무료 프로젝트인가요, 결제 연결된 유료 프로젝트인가요?**
   - 무료 등급은 콘텐츠가 Google 제품 개선에 사용될 수 있습니다.
   - 유료 등급이라면 API 로그 저장, 데이터셋 공유 및 Google과의 데이터 처리 부속약관 설정을 확인해야 합니다.
   - 현재 AI 전송 대상은 빈 시험지·정답지이며 학생 답안·점수 등은 전송되지 않습니다. 교사가 개인정보가 포함된 원본을 잘못 올리지 않도록 업로드 화면에 안내 또는 경고를 표시할까요?

6. **Gemini 국외 이전 정보를 확인할 수 있나요?**
   - API 계약상 처리 법인, 처리 국가, 문의처, 보유기간 및 국외 이전 법적 근거를 Google 계약/관리자 화면에서 확인해야 합니다.
   - 학교 또는 교육청의 국외 이전·생성형 AI 사용 승인 절차가 있나요?

7. **삭제 요청은 어떻게 접수할까요?**
   - 확인된 내용: 학생 또는 보호자의 열람·정정·삭제 요구는 학교 과학정보부가 접수·처리합니다.
   - 과학정보부의 공식 이메일이나 학교 연락처는 무엇으로 기재할까요?
   - 본인·법정대리인 확인과 처리 결과 통지 절차는 어떻게 할까요?

8. **화면 이탈 시 즉시 강제 제출 정책을 유지하나요?**
   - 학생에게 사전 고지하고, 오탐에 대한 교사 확인·재참여·이의제기 절차를 둘 계획인가요?

9. **서비스 비용과 라이선스는 어떻게 정하나요?**
   - ScoreLab 자체는 무료인가요?
   - Gemini API 비용은 각 교사 또는 학교가 부담하나요?
   - 소스와 시험 자료의 이용·재배포 조건은 무엇인가요?

10. **시행일과 변경 공지 방법은 무엇인가요?**
    - 앱 내 별도 페이지, 설치 프로그램, 학교 홈페이지 중 어디에 게시할까요?
    - 변경 전 며칠 동안 공지할지 정해야 합니다.

## B. 앱 성격 판단

- **주된 성격:** 학교 또는 교사가 사용하는 학생 수업·형성평가·학습 피드백 지원 도구
- **행정업무 여부:** 학교 공식 행정시스템과 직접 연계되지는 않지만, 학교 기준과 관련 법령에 따라 결과를 성적 처리·학생 지도·학교생활기록 작성의 참고자료로 활용할 수 있음
- **이용 대상:** 교사와 해당 시험에 참여하는 학생
- **운영 구조:** 교사 PC에서 서버·DB를 실행하고 학생이 같은 LAN에서 접속하는 로컬 설치형 구조
- **계정 구조:** 교사 단일 비밀번호만 존재. 학생 회원가입 없음. 학생은 출석번호와 무작위 시험 접근 토큰 사용

## C. 코드와 화면에서 확인한 데이터 흐름

### 로컬 저장

- `server/src/db/schema.sql`
  - `roster`: 출석번호, 선택 입력 이름
  - `exam_sessions`: 시험 참여·진행 상태, 점수, 시각, 화면 이탈로 인한 종료 사유
  - `answers`: 학생 답안, 문항별 소요시간, 정오답, 점수, 필기 획 JSON
  - `warning_events`: 화면 숨김·창 포커스 상실 시각과 누적 경고
  - `exams`, `questions`, `choices`, `question_standards`: 시험·문항·정답·성취기준·교사 메모
- `server/src/services/appSettings.js`
  - Gemini API 키, 선택 모델, 모델 캐시, 교사 비밀번호 해시, 세션 서명 비밀키를 `settings.json`에 저장
- `server/src/config.js`, `electron/main.js`
  - 설치본 데이터는 Electron 사용자 데이터 폴더 아래 `data`에 저장
  - 서버 오류 로그는 Electron 사용자 데이터 폴더 아래 `logs/server.log`에 저장
- `client/src/pages/student/StudentJoin.tsx`, `TakeExam.tsx`
  - 학생 출석번호, 시험별 접근 토큰, 필기 모드를 브라우저 localStorage에 저장
- `client/src/pages/teacher/SettingsPage.tsx`
  - 교사가 선택한 LAN IP를 브라우저 localStorage에 저장

### 외부 전송

- `server/src/services/aiExtraction.js`
  - Gemini `generateContent`로 시험지·정답지 이미지/PDF, 분석 프롬프트, 교과·학년군·성취기준 정보를 HTTPS 전송
  - 학생 답안·성적·필기 획을 Gemini에 보내는 코드는 확인되지 않음
- `server/src/services/geminiModels.js`
  - Gemini Models API로 API 키를 보내 현재 키에서 사용 가능한 모델 목록 조회
- 분석·광고·외부 클라우드 DB SDK는 확인되지 않음

### 학생 기기와 교사 PC 사이 전송

- `server/src/index.js`
  - 학생 접속 주소는 `http://LAN-IP:4000/student`
  - QR 코드는 로컬 `qrcode` 라이브러리로 생성
- 학생이 보내는 출석번호, 답안, 필기 획, 화면 이탈 기록은 교사 PC 로컬 서버에 저장
- HTTPS 또는 전송구간 암호화는 현재 확인되지 않음

### 삭제·파기

- `server/src/routes/roster.js`, `server/src/db/repo.js`
  - 명단 삭제는 `roster` 행만 삭제하며 기존 응시 기록에는 출석번호가 남음
- `server/src/routes/exams.js`
  - 일반 시험 삭제는 `archived` 숨김 처리
  - 영구 삭제는 DB 외래키 연쇄 삭제로 세션·답안·경고를 삭제
  - 문항 및 시험 DB 삭제 시 관련 이미지 파일을 함께 지우는 처리는 확인되지 않음
- `server/src/routes/backup.js`
  - 전체 복원 전 기존 DB를 `.bak-시각` 파일로 복사하며 자동 삭제하지 않음
  - 다운로드된 백업 파일은 사용자 관리
- API 키 삭제, 로그 자동 순환, 학년도 말 일괄 파기 기능은 확인되지 않음

## D. 예시 PDF에서 그대로 가져오지 않은 내용

- 예시의 회원가입·학생 아이디·비밀번호는 ScoreLab에 존재하지 않아 제외했습니다.
- 예시의 특정 학교·교사·전화번호는 사용하지 않았습니다.
- 예시의 “익년 2월 말”, “5일 이내 파기”는 현재 운영 결정과 코드 근거가 없어 사용하지 않았습니다.
- 예시의 전문 클라우드·전 구간 HTTPS 설명은 ScoreLab의 로컬 HTTP 구조와 맞지 않아 사용하지 않았습니다.
- 예시의 무료 서비스 및 비상업 운영 문구는 실제 배포·비용 정책을 확인할 수 없어 `[확인 필요]`로 남겼습니다.

## E. 법령·공식 정책 검토 근거

- 개인정보 보호법상 처리방침 수립·공개 및 안전조치 의무는 국가법령정보센터의 현행 법령을 기준으로 최종 확인해야 합니다.
- 개인정보보호위원회는 2025년 개인정보 처리방침 작성지침에서 필수사항과 권장사항을 구분하고, 국외 이전 및 자동화된 결정 등에 관한 구체적 안내를 강화했습니다.
- Google Gemini 공식 문서상 무료 등급은 입력·출력 콘텐츠가 제품 개선에 사용될 수 있고, 유료 서비스는 프롬프트·응답을 제품 개선에 사용하지 않는다고 안내합니다.
- Google은 남용 방지 목적으로 프롬프트·응답·맥락 정보를 55일 보관할 수 있다고 안내합니다.
- 유료 프로젝트의 선택적 API 로그는 기본 최대 55일이며 7·14·28·55일로 설정할 수 있고, 별도 데이터셋은 정해진 만료기간이 없을 수 있습니다.

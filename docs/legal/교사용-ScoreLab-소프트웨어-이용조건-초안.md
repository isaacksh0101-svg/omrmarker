# 교사용 ScoreLab 소프트웨어 이용조건

> 문서 상태: 검토용 초안
> 기준 버전: ScoreLab 2.0.1
> 작성 기준일: 2026-09-21
> 시행일: 2026-09-21

## 제1조 목적

이 이용조건은 isaacksh0101(이하 `배포자`)가 제공하는 로컬 설치형 수업·평가 지원 소프트웨어 ScoreLab(이하 `프로그램`)의 이용조건과 배포자 및 교사 이용자의 역할을 정합니다.

학생은 담당 교사가 개설한 시험에 참여하지만 프로그램을 설치·관리하는 이용계약 당사자는 교사 또는 학교입니다.

## 제2조 프로그램의 기능과 성격

1. 프로그램은 시험 작성·실시·채점, 학생별·문항별·성취기준별 결과 분석 및 학습 피드백을 지원합니다.
2. 프로그램은 교사 PC에서 서버와 데이터베이스를 실행하고 학생이 같은 네트워크에서 브라우저로 접속하는 로컬 방식입니다.
3. 학생 데이터는 교사 PC에 저장되며 배포자의 중앙 서버로 전송되지 않습니다.
4. 프로그램은 학교의 공식 행정시스템과 직접 연계되지 않으며 결과를 자동으로 학교생활기록부 등에 반영하지 않습니다.
5. 교사는 프로그램의 결과와 AI 제안을 직접 검토한 후 학교 기준에 따라 활용해야 합니다.

## 제3조 이용 대상과 학교 절차

1. 프로그램의 교사용 기능은 교직원 또는 학교가 사용을 허용한 사람이 이용합니다.
2. 학교에서 교육자료로 선정하여 사용하는 경우 학교의 학습지원 소프트웨어 선정, 개인정보 보호, 정보보안 및 교육활동 절차를 따라야 합니다.
3. 다른 학교 교사에게 프로그램을 전달하는 경우 수령 교사와 해당 학교도 자체적으로 사용 적정성과 필요한 승인 절차를 확인해야 합니다.

## 제4조 라이선스와 배포 범위

1. 프로그램은 무료로 이용할 수 있습니다.
2. 비상업적 목적에 한하여 설치파일을 다른 교사에게 재배포할 수 있습니다.
3. 비상업적 목적에 한하여 소스코드를 수정하고 수정본을 재배포할 수 있습니다.
4. 프로그램과 수정본을 판매하거나 유료 상품·서비스의 일부로 제공하는 등 상업적으로 이용할 수 없습니다.
5. 프로그램에 포함된 오픈소스 구성요소는 각 구성요소의 라이선스를 따릅니다.

별도의 라이선스 문서가 정해지면 그 문서가 이 조보다 우선합니다.

## 제5조 교사와 학교의 데이터 관리

1. 학교는 교육활동 중 처리되는 학생 정보의 개인정보처리자이며 담당 교사는 학교의 관리·감독 아래 프로그램을 사용합니다.
2. 교사는 교육활동에 필요한 최소한의 정보만 입력하고, 가능하면 이름 없이 출석번호를 사용합니다.
3. 교사는 학생에게 데이터 처리 항목·목적·보유기간, 화면 이탈 규칙과 문의 방법을 시험 전에 안내합니다.
4. 학생의 응시·답안·점수·소요시간·필기·화면 이탈 기록은 해당 학기 말까지 보유한 뒤 프로그램의 전체·선택 학생 또는 학년도별 삭제 기능으로 삭제합니다.
5. 교사는 백업 파일, 복원 사본, 로그와 내보낸 결과물도 학교 기준에 따라 점검·삭제합니다.
6. 학생이나 보호자의 열람·정정·삭제·처리정지 요청은 담당 교사가 접수하고 필요한 경우 학교 과학정보부의 지원을 받습니다.
7. 배포자는 학생 데이터를 보유하거나 원격 열람할 수 없으므로 학생 데이터 권리행사 요청을 직접 처리하지 않습니다.

## 제6조 네트워크와 기기 보호

1. 학생 접속은 환경설정에서 선택한 학교 관리 내부 유·무선 네트워크에서만 운영합니다. Windows 공용(Public) 네트워크에서는 학생 접속이 차단됩니다.
2. 교사는 교사 PC의 사용자 계정, ScoreLab 비밀번호, 방화벽과 저장장치를 보호해야 합니다.
3. 교사 로그인과 관리 기능은 ScoreLab이 실행되는 교사 PC의 localhost에서만 사용합니다.
4. 교사는 시험 QR·접속주소와 참여정보를 수업에 필요한 학생에게만 제공합니다.
5. 프로그램의 LAN 통신에는 현재 HTTPS가 적용되지 않는다는 점을 이해하고 학교의 보완조치를 따릅니다.

## 제7조 Gemini AI 기능

1. Gemini 기능은 선택사항이며 교사 또는 학교가 직접 발급받은 API 키를 사용합니다.
2. 각 교사 또는 학교는 자신의 API 키를 사용하며 해당 계정에서 발생하는 Gemini API 이용료와 요금제를 직접 부담·관리합니다.
3. 교사는 개인정보가 없는 빈 시험지·정답지만 AI 분석에 사용해야 합니다.
4. 학생 이름, 작성 답안, 점수, 상담자료 또는 그 밖의 개인정보가 포함된 파일을 Gemini에 업로드해서는 안 됩니다.
5. AI가 제안한 문항, 정답과 성취기준은 오류가 있을 수 있으므로 교사가 확인·수정한 후 사용합니다.
6. Gemini의 콘텐츠 이용·보관 정책은 Google의 최신 약관과 사용 중인 프로젝트 설정에 따릅니다.

## 제8조 시험 운영과 결과 활용

1. 교사는 시험 목적, 대상, 평가 방법과 학생 특성을 고려하여 문항과 운영 규칙을 결정합니다.
2. 화면 이탈 시 강제 제출 규칙을 사용하는 경우 학생에게 시작 전에 알리고 오탐 또는 불가피한 사정에 대한 확인·재참여 절차를 운영합니다.
3. 자동 채점과 분석 결과는 교사가 검토한 후 활용합니다.
4. 프로그램 장애, 네트워크 단절 또는 기기 문제로 시험 진행에 영향이 있었던 경우 교사는 학생에게 불리하지 않도록 재응시 등 적절한 조치를 판단합니다.

## 제9조 백업과 삭제

1. 교사는 중요한 자료를 학교가 허용한 저장장치에 백업할 수 있습니다.
2. 백업 파일에는 학생 정보가 포함될 수 있으므로 개인 클라우드, 개인 이메일 또는 허가되지 않은 이동식 저장매체에 보관해서는 안 됩니다.
3. 복원 전 자동 생성되는 DB 사본과 교사가 내보낸 파일은 프로그램 안의 삭제기능만으로 제거되지 않을 수 있습니다.
4. 프로그램 제거 또는 PC 교체 시 환경설정에 표시된 데이터 저장 폴더, 저장 위치 변경 전에 사용하던 폴더와 별도 백업의 삭제 여부를 확인해야 합니다.

## 제10조 업데이트와 지원

1. 배포자는 오류 수정, 보안 개선 또는 기능 변경을 위해 프로그램을 업데이트할 수 있습니다.
2. 데이터 저장·외부 전송 방식이 변경되는 경우 관련 안내서를 함께 개정합니다.
3. 제품 설치·오류·업데이트 문의: isaacksh0101@sen.go.kr
4. 사용설명서: 프로그램 하단의 `사용설명서` 팝업 및 `docs/ScoreLab-사용설명서.md`
5. 변경내역·장애 공지: https://github.com/isaacksh0101-svg/omrmarker
6. 답변 목표: 평일 기준 7일 이내

## 제11조 보증과 책임 범위

1. 배포자는 프로그램의 안정성과 정확성을 높이기 위해 합리적으로 노력합니다.
2. 프로그램과 AI 결과가 모든 환경에서 오류 없이 동작하거나 항상 정확함을 보증하지는 않습니다.
3. 교사는 시험 실시 전에 학교 환경에서 접속·저장·삭제·복구 기능을 확인해야 합니다.
4. 이용자가 안내와 학교 절차를 위반하여 개인정보가 포함된 자료를 외부 AI에 업로드하거나 백업 파일을 부적절하게 관리한 경우 그 영향은 구체적 사정에 따라 판단합니다.
5. 이 조는 관련 법령상 배제할 수 없는 배포자의 책임을 면제하지 않습니다.

## 제12조 이용 종료

교사 또는 학교는 언제든지 프로그램 사용을 중단할 수 있습니다. 사용 종료 시 학생 학습 데이터, 학생 명단, 시험 자료, 백업, 복원 사본, 로그와 학생 기기의 사이트 데이터를 학교 기준에 따라 삭제합니다.

## 제13조 조건의 변경

배포자는 기능, 보안 또는 관련 정책의 변경에 따라 이 이용조건을 개정할 수 있습니다. 중요한 변경은 ScoreLab GitHub 저장소에 게시하며, 이용자는 설치 또는 업데이트 전에 저장소의 이용조건과 변경내역을 확인해야 합니다. 별도 시행일이 표시된 경우에는 그 날짜부터 변경조건을 적용합니다.

## 부칙

이 이용조건은 2026년 9월 21일부터 적용합니다.

# ScoreLab 데이터 처리 및 개인정보 보호 안내서

> 문서 상태: 검토용 초안 — 프로그램 하단의 안내 팝업에서 확인할 수 있습니다.
> 기준 버전: ScoreLab 2.0.1
> 작성 기준일: 2026-09-21
> 시행일: 2026-09-21

## 1. 문서의 목적과 적용 범위

이 문서는 로컬 설치형 수업·평가 지원 도구인 ScoreLab이 어떤 데이터를 입력·저장·전송·삭제하는지 교사와 학교에 설명합니다.

ScoreLab 개발자는 학생 데이터를 수집·보관하거나 원격으로 열람하지 않습니다. 학생 데이터는 ScoreLab을 실행하는 교사 PC에 저장되며 개발자의 중앙 서버로 전송되지 않습니다. 학교 교육활동에서 ScoreLab을 이용하여 학생 정보를 처리하는 주체는 해당 학교이고, 담당 교사는 학교의 관리·감독 아래 프로그램을 사용합니다.

이 문서는 개발자 명의의 학생 개인정보처리방침이 아니라 제품의 데이터 처리 방식을 설명하는 안내서입니다. 학교의 개인정보 처리방침, 교육활동 계획과 내부 절차가 우선 적용됩니다.

## 2. 제품의 이용 목적과 대상

ScoreLab은 교사가 시험을 작성·실시·채점하고 학생별·문항별·성취기준별 결과를 분석하도록 지원합니다.

- 교사: 시험 작성, 시험 운영, 채점, 결과 분석 및 학습 피드백
- 학생: 담당 교사가 개설한 시험 참여
- 활용 범위: 수업, 형성평가, 평가 및 학생 지도 자료

ScoreLab은 학교의 공식 행정시스템과 직접 연계되지 않으며 결과를 자동으로 학교생활기록부 등에 전송하지 않습니다. 교사는 결과를 직접 확인한 후 학교의 평가·기록 기준에 따라 활용해야 합니다.

| 학생 브라우저 저장 | 출석번호, 시험별 무작위 접근 토큰, 필기 모드 | 재접속과 시험 세션 식별 | 학생 기기. 브라우저 사이트 데이터 삭제 전까지 |

| 백업 | 교사가 선택한 시험·명단·응시·답안·화면 이탈 기록 | 이전과 복구 | 교사가 지정한 저장장치. 사용 교사 또는 학교가 직접 보관·관리·삭제 |

ScoreLab은 코드상 학생 기기의 IP 주소, User-Agent 또는 광고 식별자를 데이터베이스에 별도 저장하지 않습니다. 학생 이름은 선택항목이며 이름 없이 출석번호만 사용할 수 있습니다.

## 4. 학교와 교사의 운영 책임

학교는 ScoreLab 사용 목적과 법적 근거, 담당자, 보유기간 및 권리행사 절차를 정합니다. 담당 교사는 다음 사항을 지켜야 합니다.

1. 교육활동에 필요한 최소한의 항목만 입력합니다.
2. 가능하면 학생 이름을 입력하지 않고 출석번호를 사용합니다.
3. 학생에게 시험 시작 전에 데이터 처리 항목, 목적, 화면 이탈 규칙과 문의 방법을 안내합니다.
4. 학기 말에 전체·선택 학생 삭제 또는 학년도별 성적 데이터 일괄삭제 기능으로 학습 데이터를 삭제합니다.
5. 개인정보가 포함된 시험지·답안지나 학생 작성물을 Gemini 분석에 업로드하지 않습니다.
6. 환경설정에서 학교가 관리하는 내부 네트워크를 선택하여 사용합니다. Windows 공용(Public) 네트워크에서는 학생 접속이 차단됩니다.
7. 교사 PC 계정, 비밀번호, 백업 파일과 ScoreLab 데이터 폴더를 안전하게 관리합니다.

## 5. 외부 전송과 Google Gemini API

### 5.1 학생 데이터

학생의 출석번호, 이름, 답안, 점수, 필기 획, 화면 이탈 기록은 개발자 서버나 Gemini API로 전송되지 않습니다.

### 5.2 AI 분석 자료

교사가 AI 문항 추출 등의 기능을 실행하면 다음 자료가 Google Gemini API로 HTTPS 전송될 수 있습니다.

- 교사가 선택한 빈 시험지·정답지 이미지 또는 PDF
- 교과, 학년군 및 성취기준 목록
- 문항 분석을 위한 지시문
- 교사가 설정한 Gemini API 키

교사는 학생 이름·답안·점수 등 개인정보가 포함된 문서를 업로드해서는 안 됩니다. 개인정보가 포함된 파일을 업로드하면 그 내용도 Google에 전송될 수 있습니다.

Gemini 사용은 선택사항입니다. API 키를 등록하지 않아도 시험과 문항을 수동으로 작성할 수 있습니다. Gemini의 처리 법인, 처리 국가, 콘텐츠 이용 및 보유기간은 교사가 사용하는 Google 프로젝트의 무료·유료 등급과 설정에 따르므로 실제 사용 전에 Google의 최신 약관과 학교의 생성형 AI 사용지침을 확인해야 합니다.

## 6. 제3자 제공과 처리위탁

현재 기본 구조에서 ScoreLab 개발자는 학생 개인정보를 제공받거나 처리업무를 위탁받지 않습니다. 학생 데이터는 교사 PC에만 저장됩니다.

정상적인 사용에서는 개인정보가 없는 빈 시험지·정답지만 Gemini로 전송하므로 학생 개인정보의 제3자 제공 또는 처리위탁을 전제로 하지 않습니다. 학교나 교사가 개인정보가 포함된 자료를 외부 AI에 업로드하려는 경우에는 별도의 법적 근거, 제공·위탁 및 국외 이전 여부를 사전에 검토해야 합니다.

향후 클라우드 동기화, 자동 오류보고, 원격지원, 중앙 계정 또는 학생 데이터 서버 저장 기능이 추가되면 이 항목을 다시 검토하고 안내서를 개정합니다.

## 7. 로컬 네트워크와 접근통제

1. 학생은 교사 PC와 같은 네트워크에서 `http://교사PC주소:4000/student` 형태의 주소로 접속합니다.
2. 출석번호, 답안, 필기와 화면 이탈 기록은 학생 기기에서 교사 PC로 전송됩니다.
3. 교사 로그인·세션 발급·관리 API와 교사 화면은 해당 교사 PC의 localhost 접속만 허용합니다.
4. 학생 세션은 순차 번호 대신 추측하기 어려운 무작위 접근 토큰으로 식별합니다.
5. 학생과 교사 PC 사이에는 현재 HTTPS가 적용되지 않습니다. 프로그램은 교사가 선택한 네트워크와 같은 서브넷의 요청만 허용하고 Windows 공용(Public) 네트워크에서는 학생 접속을 차단합니다.

## 8. 삭제와 파기

### 8.1 학생별 학습 데이터

교사가 학생 관리 화면에서 전체 또는 원하는 학생을 선택해 `선택한 학습 데이터 삭제`를 실행하면 해당 출석번호에 연결된 시험 참여, 답안, 점수, 문항별 소요시간, 필기와 화면 이탈 기록이 삭제됩니다. 학생 명단은 유지됩니다.

### 8.2 학생 명단

학생 명단은 별도 삭제할 수 있습니다. 명단 삭제만으로 과거 학습 데이터가 삭제되지는 않으므로 필요한 경우 학습 데이터를 먼저 삭제합니다.

### 8.3 시험

일반 시험 삭제는 보관·숨김 처리입니다. 시험별 영구 삭제를 실행해야 해당 시험의 세션·답안·경고 기록이 연쇄 삭제됩니다.

### 8.4 그 밖의 파일

- 학생 기기: 브라우저 사이트 데이터를 삭제해야 출석번호와 접근 토큰이 제거됩니다.
- 백업: 교사가 내보낸 백업과 이동식 저장매체 사본은 교사가 직접 삭제합니다.
- 복원 사본: 전체 복원 시 생성되는 `.bak` 파일은 별도로 확인하여 삭제합니다.
- 시험 이미지·로그·복원 사본: 자동 삭제되지 않으며 사용 교사 또는 학교가 필요 기간 보관하고 직접 점검·삭제
- 전체 데이터: 최초 실행 때 사용자가 선택하거나 환경설정의 `데이터 저장 위치`에 표시되는 폴더에서 DB, uploads, settings, 로그와 복원 사본을 확인하여 삭제합니다. 저장 위치를 변경한 경우 이전 폴더의 삭제 또는 안전한 보관 여부를 확인할 때까지 프로그램에 경고가 표시됩니다.

## 9. 학생과 보호자의 권리행사

학생 또는 보호자는 관련 법령과 학교 절차에 따라 열람·정정·삭제·처리정지 등을 요청할 수 있습니다.

- 1차 신청: ScoreLab을 사용한 담당 교사
- 신청 방법: 구두 또는 학교가 허용한 연락수단
- 지원 부서: 학교 과학정보부
- 본인·보호자 확인: 담당 교사가 학급 명단과 학교의 보호자 확인 절차로 확인
- 결과 통지 방법과 처리기한: 학교 절차에 따름 [구체적 절차 확인 필요]

개발자는 학생 데이터를 보유하거나 열람할 수 없으므로 학생 데이터의 열람·삭제 요청을 직접 처리하지 않습니다. 제품 설치·오류 문의와 학생 데이터 권리행사 요청을 구분해야 합니다.

## 10. 만 14세 미만 학생

ScoreLab에는 학생 회원가입 기능이 없지만 만 14세 미만 학생의 출석번호와 학습 기록이 처리될 수 있습니다. 학교는 교육활동 수행에 필요한 범위와 법적 근거를 확인하고, 학생이 이해하기 쉬운 표현으로 처리 항목·목적·보유기간·화면 이탈 규칙과 문의 방법을 안내해야 합니다.

동의를 근거로 별도의 선택적 처리를 하는 경우에는 학교가 법정대리인 동의와 확인 절차를 마련해야 합니다. 단순히 회원가입이 없다는 이유만으로 아동 개인정보가 처리되지 않는다고 설명하지 않습니다.

## 11. 자동 채점과 AI 보조기능

ScoreLab은 설정된 정답에 따라 자동 채점하고 Gemini를 이용해 문항·정답·성취기준 후보를 제안할 수 있습니다. AI 결과는 교사가 확인·수정해야 하며 자동으로 공식 기록에 반영되지 않습니다.

화면 이탈 규칙은 학생 시험을 강제로 제출할 수 있으므로 시험 시작 전에 알리고, 오탐 또는 불가피한 이탈에 대해서는 담당 교사가 확인하여 재참여 여부를 판단합니다.

## 12. 안전성 확보조치와 알려진 한계

### 적용된 조치

- 학생 데이터의 교사 PC 로컬 저장
- 교사 비밀번호의 scrypt 단방향 해시 저장
- 12시간 만료 HttpOnly·SameSite=Lax 교사 세션 쿠키
- 교사 로그인과 관리 기능의 localhost 제한
- 학생별 무작위 접근 토큰
- Gemini API 키의 AES-256-GCM 암호화 저장
- AI API 통신의 HTTPS 사용
- 전체·선택 학생 및 학년도별 학습 데이터 완전삭제 기능

### 운영상 보완이 필요한 사항

- 학생 기기와 교사 PC 사이의 LAN 통신은 HTTP임
- SQLite DB와 내보낸 백업 파일은 자체 암호화되지 않음
- 운영 로그·복원 사본·일부 이미지에 자동 파기기능이 없음
- 교사 비밀번호 최소 기준과 반복 실패 제한 보완 필요
- `xlsx` 라이브러리의 알려진 고위험 취약점 조치 필요

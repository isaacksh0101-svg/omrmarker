# ScoreLab 배포·업데이트·복구 안내

## 공식 배포 위치

설치 파일과 변경내역은 다음 GitHub Releases에서 제공합니다.

https://github.com/isaacksh0101-svg/omrmarker/releases

설치 파일은 `ScoreLab-Setup-버전-x64.exe` 형식입니다. 같은 Release에 있는 `SHA256SUMS.txt`와 내려받은 파일의 SHA-256 값이 같은지 확인한 뒤 실행합니다.

현재 초기 배포본은 공인 코드서명 인증서 없이 제공됩니다. 따라서 Windows에 `알 수 없는 게시자` 또는 SmartScreen 경고가 표시될 수 있습니다. 이는 설치 파일이 자동으로 위험하다는 뜻은 아니지만, 반드시 이 GitHub Releases에서 직접 내려받고 공개된 SHA-256 값과 일치하는지 확인해야 합니다. 메신저·메일 등으로 다시 전달된 설치 파일은 사용하지 않는 것을 권장합니다.

```powershell
Get-FileHash .\ScoreLab-Setup-2.3.0-x64.exe -Algorithm SHA256
```

## 수동 업데이트

1. ScoreLab의 데이터 관리 화면에서 백업 파일을 만듭니다.
2. ScoreLab을 완전히 종료합니다.
3. GitHub Releases에서 새 설치 파일과 `SHA256SUMS.txt`를 받습니다.
4. SHA-256 값을 확인합니다.
5. 새 설치 파일을 실행하여 기존 설치 위치에 덮어 설치합니다.
6. 실행 후 버전 변경내역과 기존 시험·학생 데이터가 정상인지 확인합니다.

설치 제거 시 사용자가 선택한 데이터 저장 폴더는 자동 삭제하지 않습니다.

## 이전 버전으로 복구

1. 현재 데이터 폴더와 백업 파일을 별도 위치에 복사합니다.
2. ScoreLab을 제거합니다. 데이터 삭제 여부가 표시되면 데이터를 유지합니다.
3. GitHub Releases에서 필요한 이전 버전 설치 파일과 그 버전의 해시 파일을 받습니다.
4. 해시 확인 후 이전 버전을 설치합니다.
5. 새 버전에서 데이터베이스 구조가 변경되었다면 새 버전 사용 전에 만든 백업을 복원합니다.

새 버전에서 이미 사용한 데이터베이스를 이전 버전으로 직접 여는 것은 지원하지 않습니다. 반드시 해당 버전과 호환되는 백업을 사용하세요.

## Windows 코드서명 확인

서명된 배포본에서는 설치 파일 속성의 `디지털 서명` 탭에서 서명자와 유효성을 확인할 수 있습니다. 서명이 없거나 유효하지 않은 파일은 배포 페이지의 안내와 해시를 다시 확인하세요.
